RaGuard · System Architecture

A heterogeneous agentic pipeline that finds, confirms, and fixes web vulnerabilities.

A generalist orchestrator routes narrow specialist SLMs, grounds its analysis in a RAG knowledge base of CWE/CVE, and closes the loop by dynamically confirming each static finding with a fuzzer — running fully locally, against a target sealed in a container.

Using these for the defense: open full-screen on the projector, or screenshot each plate straight into a slide — the dark plates hold up on both projector and print.

Diagram source lives in docs/architecture.md; the demo walk-through is in docs/demo_runbook.md.
